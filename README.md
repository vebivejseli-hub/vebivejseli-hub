## Open source: Bounded Agent Runtime

### [BAR — Bounded Agent Runtime](https://github.com/steerion-labs/bounded-agent-runtime)

> **Give coding agents freedom to work. Keep authority out of the model.**

BAR is an open-source, model-agnostic security runtime for autonomous coding agents.

It lets tools such as **Codex, Claude Code, OpenCode, containers, or custom agents** build and review code inside explicit boundaries, while a deterministic controller keeps scope, evidence, budgets, and protected-action authorization outside the LLM.

```text
Task → Builder → Verified Candidate → Reviewer → Human Gate
```

**Core principle:** capability is not authority.

BAR is designed for teams experimenting with autonomous coding, multi-agent Builder/Reviewer workflows, and security-conscious automation where the model should never become the final authorization boundary.
